Programa en Python

def saludar(nombre):
    print("Hola, " + nombre)

for i in range(3):
    if i % 2 == 0:
        saludar("DAM")
    else:
        print("Número impar:", i)

Cómo ejecutarlo

Guarda el código en un archivo llamado saludo.py, abre una terminal con Ctrl + Alt + T, escribe python3 saludo.py y pulsa Enter. La salida será:

Hola, DAM
Número impar: 1
Hola, DAM
